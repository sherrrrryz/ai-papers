# Papers

Put PDFs here (subfolders are fine). Name each file like this so the table can fill in its columns:

```
<year>_<type>_<sub type>_<title>.pdf
```

For example `2024_Full Paper_LLM Agents_Designing Conversational Agents for Older Adults.pdf`.

Files that don't follow the pattern still show up: the year is picked up from anywhere in the name, and the rest becomes the title. You can correct any field afterwards in `data/papers.json`; edits are kept when the list is rebuilt.
